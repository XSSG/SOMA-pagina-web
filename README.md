# SOMA · Tus manos, tu ritmo.

Sitio web de **SOMA**, mango ergonómico de cocina para personas con poca fuerza o movilidad en las manos.
Proyecto académico · Practicum 2 · Universidad Anáhuac Mayab.

## Páginas
- `index.html`: Inicio
- `producto.html`: Producto y pedido
- `quienes-somos.html`: Misión, visión, justificación y equipo
- `contacto.html`: Formulario y redes

## Estructura
- `css/`: `base.css` (paleta y tipografía), `components.css`, `pages.css`, `fonts.css` (Adobe Fonts), `interacciones.css`
- `js/`: `main.js`, `interacciones.js`, `inicio.js`, `producto.js`, `contacto.js`
- `img/producto/`: renders y fotos del mango · `img/marca/`: logo, imagotipo y favicon

HTML, CSS y JavaScript puro, sin dependencias ni paso de compilación.
